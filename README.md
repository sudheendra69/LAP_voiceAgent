🚀 **Project Spotlight: AI-Powered Loan Eligibility Voice Agent | Retell AI**

I’m excited to share a voice AI agent I built using **Retell AI** for a Loan Against Property (LAP) preliminary eligibility assessment workflow inspired by Home Credit.

🎯 **Project Objective**  
To automate initial customer conversations, collect eligibility information naturally, and determine whether a customer meets the preliminary criteria for the next step.

💡 **Key Features**
- 🗣️ Natural, conversational voice interactions.
- 🔐 Customer identity verification before disclosing offer details.
- 📋 Automated preliminary eligibility checks across seven criteria.
- 🧠 Context-aware response handling that captures multiple answers from a single customer response and avoids asking the same questions again.
- ⚠️ Immediate handling of disqualifying conditions.
- 🔄 Separate routing for existing loan-transfer enquiries.
- 🤝 Structured handoff to a senior loan expert when all eligibility checks are satisfied.
- 🛡️ Responsible responses without promising loan approval or inventing financial terms.

🛠️ **Technology Used:** Retell AI, conversational prompt engineering, voice agent workflows, and rule-based eligibility logic.

This project helped me explore how carefully designed prompts, conversation state management, and decision rules can make voice agents more consistent and useful in real-world customer interactions.

I’m looking forward to building more practical AI automation solutions and improving my skills in **Generative AI, conversational AI, and AI agent development**.
